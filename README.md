# 🌾 AGMATIX AI PRO

**Professional decentralized agricultural intelligence and marketplace for the Pi Network.**

AGMATIX AI PRO connects farmers, buyers, and investors on the Pi Network. Access real-time crop analytics, AI-driven price predictions, and a trustless commodity marketplace — all in one platform.

---

## Features

- 🤖 **AI Crop Analytics** — ML models for yield forecasting, disease detection, and planting recommendations  
- 🛒 **Pi Marketplace** — Buy and sell agricultural commodities directly using Pi coin  
- 📈 **Price Intelligence** — Real-time commodity price feeds with AI predictions  
- 💼 **Portfolio Tracker** — Monitor holdings, track P&L, and export data as CSV or JSON  
- 🌍 **Global Network** — Connect with farmers and buyers worldwide  
- 🔒 **Secure & Decentralized** — Built on the Pi Network's open blockchain  

---

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or later  
- npm v9 or later  

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

The app will be served at `http://localhost:3000`.

### Deploy to GitHub Pages

```bash
npm run deploy
```

This publishes the `public/` directory to the `gh-pages` branch via [gh-pages](https://github.com/tschaub/gh-pages).
